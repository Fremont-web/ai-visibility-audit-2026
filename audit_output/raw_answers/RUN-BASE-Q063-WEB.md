### 3. Understanding Used Ram Warranty Types

When evaluating a used Ram truck, make sure you understand which type of warranty applies:

1. **Transferable Factory Warranty:** The original Ram factory warranty (3-year/36,000-mile basic limited warranty; 5-year/60,000-mile gas or 5-year/100,000-mile diesel powertrain warranty) automatically transfers to subsequent owners. Check the vehicle's original "in-service date" to calculate remaining months and miles.
2. **Manufacturer Certified Pre-Owned (Mopar CPO):** Available **only** at authorized Ram franchises (like Fremont CDJR Cody/Powell or Lithia Billings). Honored at any Ram dealership nationwide with factory-authorized parts and certified technicians.
3. **Dealer-Backed Limited Warranties:** Provided directly by dealership groups (e.g., Fremont Certified/Elite or Denny Menholt's 3-month/3,000-mile warranty). Confirm whether repairs must be completed at the selling dealer or can be performed at any licensed repair facility.
4. **Vehicle Service Contracts (Extended Warranties):** Third-party or Mopar Vehicle Protection (MVP) plans purchased at signing. If buying from an independent dealer (such as Stick Shift Motors in Cody), vehicles are usually sold "as-is" unless you add one of these contracts.
