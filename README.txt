Antigravity multi-model audit inputs

1. Extract this package into a new audit workspace.
2. Paste controller_prompt.txt into the controller conversation.
3. The controller uses consumer_questions.csv (194 exact questions), repeat_questions.csv (36 preselected questions) and neutral_respondent_protocol.txt.
4. Respondents must have fresh, separately controlled contexts. They must not inherit the controller prompt, this README, prior scores, target-company information or other answers. Separate folders alone do not prove context isolation.
5. input_manifest.json records question counts and hashes. It contains no prior scores or answers.

Question wording is unchanged from the October 6-7, 2026 audit bank. All prior outcome, status and score columns were removed. The package does not include the earlier report, answers or dealer scorecards.
